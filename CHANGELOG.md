# Changelog

All notable changes to the Robot Master Control app will be documented in this file.

## [1.0.0] - 2024-01-15

### Added
- Initial release of Apex Rover Control
- Dashboard page with real-time battery and robot status monitoring
- Control page with intuitive movement controls and joystick
- Sensors page with live sensor data visualization
- Connection page with MQTT and WebSocket support
- System page with database monitoring and error logging
- About page with app information and support links
- State management with Riverpod
- SQLite database for local data persistence
- MQTT protocol support for robot communication
- WebSocket support for real-time bidirectional communication
- Battery status alerts and warning system
- Sensor reading history and logging
- Audit log tracking
- Multiple color themes

### Features
- ✅ Real-time battery voltage, current, and power monitoring
- ✅ Robot state monitoring (ON/OFF, Charging, Mode)
- ✅ Movement control with forward, backward, turn left, turn right, and stop
- ✅ Speed adjustment slider
- ✅ Multiple sensor support (Temperature, Humidity, Distance, Infrared, Light)
- ✅ Connection status and signal strength indicator
- ✅ Auto-reconnect functionality
- ✅ System health monitoring
- ✅ Error and warning alerts
- ✅ Audit log viewing
- ✅ Responsive UI with Material Design 3
- ✅ Dark mode support

### Technical
- Flutter 3.0+
- Dart 3.0+
- Riverpod state management
- MQTT5 client
- WebSocket support
- SQLite database
- Material Design 3 theming
